# NIRVAN '26 | Technical Fest Website

## About
NIRVAN '26 is the annual technical fest of **GEHU Campus**, bringing together developers, innovators, designers, and technology enthusiasts for two days of challenges, competitions, workshops, and collaboration.  
This repository contains the source code for the official event website.

## Features
- Responsive design with modern layout  
- Event details (Hackathon, Workshop, CTF, E-Sports, Treasure Hunt)  
- Event schedule section  
- Speakers showcase  
- Gallery section  
- Registration forms for each event  
- Contact & Venue details  

## Tech Stack
- **HTML** – Structure  
- **CSS** – Styling
